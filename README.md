# Nomcebo Printers Website

Modernised website for Nomcebo Printers, Lydenburg. Static HTML/CSS with a glassmorphism design and a PHP quote-request handler.

## Pages
Home, About Us, Prints, Installations, Other, Blog, Contact Us

## Run locally
Copy the folder to `C:\xampp\htdocs\`, start Apache in XAMPP and open `http://localhost/nomcebo-printers/`.

## Notes
- `quote.php` sends quote requests with PHP `mail()`, so it needs mail configured on the host.
- Site images live in `assets/` (see `assets/README.txt` for the list).
